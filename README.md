## 📌 Overview
This repository contains the presentation deck (`Polymorphism_in_Java_LADS_DIU_BY _S M KAIF.pptx`) created for our **Object-Oriented Programming (OOP)** course at the **Department of Software Engineering, Daffodil International University (DIU)**[cite: 4].

The presentation explores how Java achieves polymorphism across both compilation and runtime phases—covering method overloading, method overriding, upcasting, JVM `invokevirtual` vtable dispatch, and real-world pluggable software architectures[cite: 4].
